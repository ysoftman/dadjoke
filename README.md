# dadjoke

Korean dad jokes (아재개그) web app.

Live: <https://ysoftman.github.io/dadjoke/>

## Features

- Dark mode (system preference + manual toggle)
- Search with keyword filtering
- Shuffle and random joke
- Infinite scroll
- Keyboard accessible cards
- Responsive design

## Development

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```

Outputs to `docs/` for GitHub Pages deployment.

## Deployment

Automatically deployed via GitHub Actions on push to `main`.
See [SLACK.md](SLACK.md) for Slack notification setup.
